# Contributing to Zoharix Pay + Tickets

Thanks for helping build this platform! Follow these simple rules to keep things organized.

## Branch Naming

- `feat/<feature-name>` → New feature
- `fix/<issue-name>` → Bug fix
- `docs/<doc-name>` → Documentation changes
- `chore/<task>` → Miscellaneous tasks

## Workflow

1. Fork the repository (or branch from main if internal)
2. Create a branch using the naming convention
3. Make your changes
4. Push the branch
5. Open a pull request with a short description

## Docs Folder

- All project documentation (diagrams, flowcharts, design notes) goes in `docs/`.
- Include your name and date in the file name.
- Keep diagrams clear and concise.
